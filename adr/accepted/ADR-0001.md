# ADR-0001: Agent execution boundaries
Status: Accepted
Risk: high

## Context
Coding agents produce untrusted changes for cloud delivery.

## Decision
Agents must not receive production credentials. Only the deployment pipeline may obtain short-lived deployment credentials after human approval.

## Alternatives
Shared credentials were rejected because they obscure accountability.

## Consequences
Keep development sandboxes isolated from production.

## Acceptance criteria
Tests prove that agent identities cannot acquire production deployment permissions.

## Rollback
Disable agent dispatch and revoke the affected deployment identity.
