# ADR-0002: Isolated code generation
Status: Proposed
Risk: low

## Context
Coding agents need to generate changes for AWS and GCP targets.

## Decision
Use ephemeral workspaces with read-only repository access and no production credentials. The agent returns a patch for review; the deployment pipeline alone may acquire short-lived deployment credentials after human approval.

## Alternatives
Persistent shared workspaces are rejected due to cross-task contamination.

## Consequences
Workspaces are deleted after review; patches are retained as CI artifacts.

## Acceptance criteria
A test verifies that the sandbox cannot read production credentials. A second test verifies that the returned patch is available for human review.

## Rollback
Disable agent dispatch and delete the affected sandbox.
