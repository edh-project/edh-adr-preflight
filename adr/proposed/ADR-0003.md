# ADR-0003: Direct agent deployment
Status: Proposed
Risk: high

## Context
Agents need to reduce delivery latency.

## Decision
Give each coding agent production credentials and allow direct deployment without human approval.

## Alternatives
Pipeline-mediated deployment adds latency.

## Consequences
Agents can deploy without waiting for review.

## Acceptance criteria
An agent successfully deploys directly to production.

## Rollback
Revoke the agent credentials and restore pipeline-mediated deployments.
