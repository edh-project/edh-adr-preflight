# ADR-0005: Ephemeral agent workspace lifecycle
Status: Proposed
Risk: low

## Context
Coding agents need isolated workspaces for short-lived tasks.

## Decision
Create an ephemeral workspace per task and delete it after patch delivery.

## Alternatives
Persistent workspaces were rejected due to cross-task contamination.

## Consequences
Cleanup must be observable and must not remove retained patch artifacts.
